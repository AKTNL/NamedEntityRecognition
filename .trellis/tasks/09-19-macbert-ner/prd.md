# MacBERT与中文NER经典论文分享与复现系统

## Goal
构建一个集“经典论文研读汇报（单文件纯离线自包含 HTML 互动系统）”与“基线复现实验闭环（CLUENER2020 + MacBERT/BERT）”于一体的高水准课程综合实践方案。该系统以 MacBERT 为核心创新模型，以 BERT（技术演进源头）与 CLUENER2020（中文细粒度 NER 评测基准）为两翼，完美覆盖《自然语言处理》课程任务书要求的 9 大论文讲解要点，并为后续基线模型复现与错例分析提供无缝对照。

## Requirements
1. **交付形态与工程架构**：
   - **单文件纯离线自包含（Single Standalone HTML）**：完全零外部 CDN、零网络请求依赖，内置所有 CSS 变量主题、现代排版引擎、高质感矢量图表（Inline SVG）与数学公式渲染，双击秒开，U 盘离线运行无阻，支持 `Ctrl+P` 导出无损 PDF。
   - **双模合一（Dual-View System）**：
     - **演示模式（Presentation Mode）**：全屏幻灯片流，支持键盘左右/上下箭头翻页、空格翻页、全屏模式（快捷键 `F`）、快速目录抽屉跳转、当前页码/进度指示条。
     - **文档精读模式（Article Mode）**：一键切换为类似顶会技术白皮书/长篇研读报告排版，适合任课教师课后细细审阅。
   - **科技极简自适应主题**：默认深色科技黑（Deep Slate/Cyan Accent），右上角支持一键秒切高校学术浅色（Academic Light），打印与投影兼顾。
   - **元数据占位符配置**：顶部集中配置小组信息（`第 [X] 组`、成员占位符），一处修改全局生效。

2. **完整覆盖《作业说明》经典论文讲解 9 大核心要素**：
   - **第 1 讲 · 研究背景**：中文命名实体识别（NER）的本质、应用价值及特有挑战（无显式词边界、多义性、嵌套与边界模糊）。
   - **第 2 讲 · 任务定义**：输入字符序列、输出标签空间（BIO 标注体系：`B-XXX`, `I-XXX`, `O`）及序列标注数学建模。
   - **第 3 讲 · 技术路线演进**：从传统规则词典 $\to$ 统计机器学习（HMM / CRF） $\to$ 深度学习时代（BiLSTM-CRF） $\to$ 预训练大模型时代（BERT） $\to$ 中文针对性纠错演进（MacBERT）。
   - **第 4 讲 · MacBERT 核心模型原理（重点核心 60%）**：
     - Transformer 双向自注意力机制与编码表示；
     - 痛点破局：解决原生 BERT 预训练与微调的不一致（Pretrain-Finetune Discrepancy）；
     - 纠错式掩码机制（MLM as Correction）：使用同义词/相似词替换原词，将掩码转为纠错还原；
     - 中文全词掩码（WWM, Whole Word Masking）与 N-gram Masking（结合 LTP 分词，保留实体边界）；
     - 训练策略改进：Sentence Order Prediction (SOP) 代替传统 NSP；
     - 下游序列标注适配：字符隐状态接分类头（Linear / Softmax / CRF）。
   - **第 5 讲 · 评测基准与数据集（CLUENER2020）**：
     - 中文细粒度 NER 基准 CLUENER2020 的提出背景；
     - 10 大实体类型（地址、书籍、公司、游戏、政府机构、电影、姓名、组织、职位、景点）的分布与难度；
     - 严格实体级评测指标：Seqeval 标准下的 Precision, Recall, Entity-level $F_1$ 值（区分精确匹配与部分匹配）。
   - **第 6 讲 · 论文实验结果与消融分析**：
     - 原文在多个中文 NLU 任务及分类基准上的表现；
     - 消融实验分析：Correction 替换策略贡献度、WWM 策略贡献度。
   - **第 7 讲 · 创新点与对中文 NER 的独特优势**：
     - 彻底消除下游不存在 `[MASK]` 的语义偏差；
     - 针对中文词汇与实体边界的天然契合性（WWM 保留实体完整性）；
     - 高样本利用率与高效收敛特性。
   - **第 8 讲 · 局限性与未来展望**：
     - 词粒度切分依赖分词工具的准确率误差传递；
     - 针对嵌套实体（Nested NER）与非连续实体的建模边界；
     - 大语言模型（LLM）In-Context Learning 时代与专用判别小模型在 NER 工业落地上的权衡。
   - **第 9 讲 · 基线复现设计与实验闭环**：
     - 统一微调基准设计：`google-bert/bert-base-chinese` vs `hfl/chinese-macbert-base`；
     - 规范预留实验环境配置、训练超参数、指标对比沙盘与 Bad Case 槽位。

3. **集成三大高互动演示组件**：
   - **组件 ①：掩码机制演进对比器（Interactive Masking Simulator）**：可在单字 Mask、全词 WWM Mask、MacBERT 相似词替换之间一键切换并查看悬浮高亮与语义分析。
   - **组件 ②：CLUENER 实体标注与 BIO 体系拆解视窗（Entity Inspector）**：动态文本段落，支持 10 类标签过滤高亮，悬浮显示字符索引与 BIO 对应标签。
   - **组件 ③：基线复现对比沙盘与 Bad Case 交互卡片（Benchmark Dashboard）**：可交互数据对比表与折叠式错例分析（边界切分错误、细粒度类别混淆）。

## Acceptance Criteria
- [ ] 单文件 HTML 独立运行，无需联网，在本地浏览器（Chrome/Edge 等）直接打开即可流畅运行无报错。
- [ ] 幻灯片模式支持键盘上下/左右方向键、空格键平滑翻页，支持快捷键 `F` 切换全屏，支持右上角全屏目录抽屉跳转。
- [ ] 右上角提供“演示模式 / 研读长文”一键切换按钮，且状态记忆顺畅。
- [ ] 右上角提供“深色科技 / 学术浅色”主题切换按钮，两种模式下颜色对比度优秀、排版优雅。
- [ ] 完整包含《作业说明》经典论文分享所要求的 9 大板块，逻辑主线紧凑严密（MacBERT 核心 + BERT 渊源 + CLUENER 落地）。
- [ ] 三大原生交互组件操作顺畅无卡顿，展示专业硬核。
- [ ] 预留清晰的基线复现数据与 Bad Case 插槽，为后续实验数据回填提供规范接口。

## Definition of Done
- 页面代码整洁、注释规范，所有 CSS 与 JS 均自包含在单文件中。
- 浏览器控制台无任何 404、网络请求失败或脚本抛错。
- 经打印预览（Ctrl + P）测试，排版无重叠截断，支持导出为高质量答辩 PDF。

## Out of Scope
- 在大规模未标注语料库上从零进行 MacBERT 的预训练（Pre-training），统一采用官方预训练模型做下游微调。

## Technical Approach
- 采用原生现代化 HTML5 + CSS3 (Flexbox/Grid/CSS Variables) + ES6 Vanilla JS 构建，零外部依赖，极速加载。
- 架构图、流程图和示意图均采用内嵌矢量 SVG 绘制，保证缩放无损、色彩与深浅主题自适应。
- 数学公式与网络结构图通过语义化 HTML + CSS 布局呈现，兼顾无网络运行与极致清晰度。

## Implementation Plan
- **PR1: 基础框架与双模调度引擎构建**
  - 构建单文件骨架，集成 CSS 主题变量系统（深色/浅色自适应）、幻灯片全屏切换引擎（键盘监听、进度条、全屏支持）与双模（Slide / Article）视图切换器。
- **PR2: 核心内容注入（完整 9 大要点体系化呈现）**
  - 编排 9 个核心章节的内容：背景、BIO 定义、技术路线演进、MacBERT 深度原理解析（含纠错掩码与 WWM）、CLUENER 数据集与评测、原著实验消融、创新点、局限与展望、基线复现设计。
- **PR3: 三大硬核交互组件实现与精细化润色**
  - 开发掩码机制对比器、CLUENER 实体拆解视窗、复现对比沙盘与 Bad Case 展开卡片；加入打印样式（Print Media Query）与快捷键指引。
